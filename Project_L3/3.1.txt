Discussion about randomness

In this task, we generated 1000 random numbers using NumPy (np.random.rand). 
These numbers are between 0 and 1 and follow a uniform distribution.
Even though we call them random, they are actually pseudo-random. 
This means they are generated by a deterministic algorithm, but for most cases they behave like real random values.
From the histogram, we can see that the values are spread across the entire interval. 
The bars are not perfectly equal, but that is normal because randomness always includes small variations.
If we run the code multiple times, the histogram will look slightly different each time. 
Also, if we generate more numbers, the distribution will become more uniform.
Overall, this experiment shows how random numbers can be generated and visualized in Python.
